# Keep a Changelog format

Used by most repos that have a CHANGELOG.md. Newest version first.

```
## [1.4.0] - 2026-11-02
### Added
- ...
### Changed
- ...
### Fixed
- ...
```

Map this skill's groups onto it: New -> Added, Improved -> Changed, Fixed -> Fixed, and put
Breaking changes first under Changed with a **BREAKING:** prefix. Keep an `## [Unreleased]`
section at the top if the file already has one.
